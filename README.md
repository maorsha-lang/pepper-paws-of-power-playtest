# Pepper: Paws of Power — playtest

[Play the game](https://maorsha-lang.github.io/pepper-paws-of-power-playtest/)

Desktop: keyboard/mouse or Xbox-compatible controller. Phones: landscape touch controls. Xbox: stick/D-pad move, A jump, B dodge, X claw, Y bite, RB grab, Menu pause, View Controls. Menus use A confirm/B back. Progress stays in the current browser. Game and media © Maor Shamir; no redistribution license is granted.

This repository contains only the playable distribution, not original source photos, references or development tools.
